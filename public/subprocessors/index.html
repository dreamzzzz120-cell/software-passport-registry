Subprocessors & Infrastructure

SPR uses third-party infrastructure and service providers to operate the product. The exact services used can change as the platform evolves; the applicable Privacy Policy, DPA and provider terms govern current use.

Hosting and delivery

Vercel — web application delivery and hosting for the public application.

Railway — application/worker runtime and managed infrastructure.

Authentication and application services

Firebase / Google Cloud — authentication and associated application services configured for SPR.

Payments

Stripe — payment processing and subscription/billing infrastructure where enabled.

Software evidence sources

GitHub — repository and source metadata acquisition where a customer submits a supported public repository or connects an authorized source.

OSV — open-source vulnerability intelligence used by SPR's security scanning workflows.

AI and optional services

Some product workflows may use optional third-party AI or monitoring services when configured. SPR does not represent optional services as universal requirements for every customer or every workflow.

Provider changes

Providers may be added, removed or changed as the service develops. Material changes are handled according to applicable contractual and privacy requirements.
