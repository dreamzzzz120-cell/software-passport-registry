Security

Software Passport Registry is an evidence-first software trust platform. Security claims on this page are limited to controls and architecture we can document; SPR does not claim a certification it does not hold.

Application security

  • Authentication is handled through Firebase Authentication.
  • Authorization uses application roles and workspace/client scoping.
  • Sensitive endpoints use validation and rate limiting where implemented.
  • Audit and evidence-integrity controls are used for security-relevant records.
  • Production services use HTTPS/TLS for network transport.

Data protection

SPR minimizes claims about data protection that cannot be independently observed. Storage, backups, encryption-at-rest controls and provider-specific safeguards depend on the configured infrastructure providers and service configuration. Customers should review the current Privacy Policy, DPA and applicable provider terms before submitting sensitive material.

Access

Customer access is intended to be restricted by authenticated identity, organization membership, role and client scope. SPR's product design treats cross-tenant isolation as a security boundary.

Incident response

Security concerns should be reported promptly to contact@softwarepassportregistry.com with “Security” in the subject. Do not send credentials, API keys, private keys or other secrets in an email.

Independent assurance

No certification claim: SPR does not currently claim SOC 2, ISO 27001, a government security certification, or a third-party penetration-test certification unless a current report is explicitly published.

Responsible disclosure

Please provide the affected URL or component, a concise description, reproduction steps where safe, and the potential impact. We will acknowledge receipt when practicable and will avoid requesting unnecessary personal or confidential information.
